## 2. 건설 현장에서의 협동로봇 수요/도입 현황

- 2024년 기준 건설업체 중 7.7%가 대부분 프로젝트에 로봇공학 활용, 19.2%는 여러 프로젝트에서 사용 경험, 34.6%는 파일럿 진행 중
- 2033년까지 건설업체 60% 이상이 어떤 형태로든 로봇 시스템 도입 전망
- 도입 동인: 건설업은 산재 사망의 약 1/5을 차지하는 고위험 산업 → 벽돌쌓기, 오버헤드 드릴링 등 반복 위험 작업 자동화로 안전성 제고
- 생산성 사례: 특정 기계 도입으로 노동생산성 3배 증가 사례, 샌딩 작업 12시간 → 3.5시간 단축 사례
- 협동로봇은 근로자 "대체"가 아닌 "협업"으로 인력난 완화에 기여
- 출처: https://constructionreviewonline.com/knowhow/2025/01/cobots-on-the-rise-transforming-work-across-diverse-industries/
