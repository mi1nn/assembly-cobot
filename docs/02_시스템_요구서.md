## 2.1 기능 요구사항

| ID | 기능 요구사항 |
| --- | --- |
| SYS-FR-01 | 시스템은 현장 관리자가 작업 지시를 생성하고 관리할 수 있어야 한다. |
| SYS-FR-02 | 시스템은 작업 대상과 작업에 적용할 Installation Target을 연결할 수 있어야 한다. |
| SYS-FR-03 | 시스템은 Installation Target에 정의된 작업 순서와 작업 조건을 관리할 수 있어야 한다. |
| SYS-FR-04 | 협동로봇 작업 관리 노드는 실행 가능한 Work Order를 조회할 수 있어야 한다. |
| SYS-FR-05 | 협동로봇 작업 관리 노드는 Work Order에 연결된 Installation Target의 작업 순서와 Operation Parameter를 조회할 수 있어야 한다. |
| SYS-FR-06 | 시스템은 작업 단계별 상태를 관리할 수 있어야 한다. |
| SYS-FR-07 | 시스템은 작업 시작, 완료, 실패 및 재시도 등의 작업 이력을 기록할 수 있어야 한다. |
| SYS-FR-08 | 시스템은 로봇 상태 및 작업 오류를 기록할 수 있어야 한다. |
| SYS-FR-09 | 시스템은 작업 결과 및 측정 결과를 저장할 수 있어야 한다. |
| SYS-FR-10 | 시스템은 작업 시작 전에 로봇 Tool, TCP, 속도 및 기준 좌표계를 초기화해야 한다. |
| SYS-FR-11 | 로봇은 지정된 공급 위치에서 기둥을 Pick해야 한다. |
| SYS-FR-12 | 로봇은 기둥을 지정된 주춧돌에 설치해야 한다. |
| SYS-FR-13 | 높이가 다른 기둥을 지정된 위치에 각각 설치해야 되며 안정적으로 지지되어야 한다.  |
| SYS-FR-14 | 로봇은 잠금핀 공급 위치로 이동하여 기둥-주춧돌 체결용 잠금핀을 직접 Pick해야 한다. |
| SYS-FR-15 | 로봇은 기둥과 주춧돌의 체결 구멍에 잠금핀을 일정 깊이까지 1차 삽입해야 한다. |
| SYS-FR-16 | 로봇은 1차 삽입된 잠금핀을 다시 파지하거나 가압하여 최종 위치까지 완전히 삽입해야 한다. |
| SYS-FR-17 | 로봇은 프레임을 Pick하여 설치된 기둥의 상부 브라켓 위에 안착시켜야 한다. |
| SYS-FR-18 | 로봇은 스냅핏 구조를 이용해 Frame을 기둥 구조물에 고정해야 한다. |
| SYS-FR-19 | 로봇은 태양광 패널을 Pick해야 한다. |
| SYS-FR-20 | 로봇은 패널을 Frame 받침대에 걸치도록 자세를 배치해야 한다. |
| SYS-FR-21 | 로봇은 스냅핏 구조를 이용해 패널을 Frame에 설치해야 한다. |
| SYS-FR-22 | 시스템은 전체 작업의 정상 완료 또는 오류 상태를 구분할 수 있어야 한다. |

> **2026-08 설계 변경**: Frame 좌표계 측정(P1/P2/P3 기준점 측정 → UCS 생성 → 좌표계 기준 패널 설치)은 더 이상 사용하지 않는 기술로 확정되어 기존 SYS-FR-18~20, 23을 제거했다. Frame·Panel 체결은 Lock Pin 2단계 삽입이 아닌 스냅핏 구조(SYS-FR-18, 21)를 사용하며, Lock Pin 2단계 삽입 기법(SYS-FR-14~16)은 기둥-주춧돌 체결로 이동했다. 상세는 CLAUDE.md·`docs/10_최종_시스템_시나리오.md` 참조. 각 SYS-FR의 실제 로봇 코드 구현 범위는 `docs/03_기능_요구서.md`를 참조한다.

| SYS-NFR-04 | 조립성 | 잠금핀 및 결합부는 로봇이 삽입하기 쉬운 구조여야 한다. |

## 2.3 외부 인터페이스

시스템은 다음과 같은 주요 연결 구조를 가진다.

> **현장관리자 ↔ UI ↔ ROS2 ↔ M0609 Robot ↔ Controller ↔ Gripper ↔ 조립 대상 구조물**
> 

로봇 프로그램은 DART/DRL 환경을 사용하며, 그리퍼는 Digital I/O를 이용하여 Open/Close 동작을 제어하는 것을 기본으로 한다.

세부 연계 항목은 4. 인터페이스 요구사항 참조.

## 2.4 제약사항

- M0609의 작업반경을 벗어나지 않아야 한다.
- 각 부품의 무게는 M0609 및 End Effector의 허용 Payload 이하이어야 한다.
- 잠금핀(기둥-주춧돌 체결용)은 로봇 그리퍼가 안정적으로 잡을 수 있는 크기와 형상이어야 한다.
- 잠금핀 삽입 방향에는 로봇이 접근할 수 있는 충분한 공간이 확보되어야 한다.
- 프레임 하중을 스냅핏 구조만으로 지지해서는 안 된다.
- 프레임의 하중은 기둥 상부 Bracket의 안착면이 지지해야 한다.
- 스냅핏 구조는 프레임·패널의 이탈 방지 및 기계적 체결 역할을 수행해야 한다.
- 구조물 체결에는 자석을 사용하지 않는다.
- 부품의 형상 인식 기능은 구현하지 않는다.
- 부품의 임의 위치 탐색 기능은 구현하지 않는다.
- 작은 볼트와 너트의 자동 체결은 프로젝트 범위에서 제외한다.
