# 4. 인터페이스 요구사항

> 상위 문서: 2. 시스템 요구서
> 

| IF ID | 연계 대상 | 연계 방식 | 송수신 데이터 | 실행 주기 |
| --- | --- | --- | --- | --- |
| IF-01 | M0609 ↔ Controller | 로봇 내부 통신 | Joint/Task Position, Motion Command | 실시간 |
| IF-02 | Controller ↔ Gripper | Digital I/O | Grasp / Release | 동작 시 |
| IF-03 | Robot ↔ Column | 물리적 인터페이스 | 삽입 위치 및 자세 | 기둥 설치 시 |
| IF-04 | Robot ↔ Frame | 물리적 인터페이스 | Frame Pick/Place 좌표 | 프레임 설치 시 |
| IF-05 | Robot ↔ Lock Pin | 그리퍼 파지 및 F/T 힘 제어 삽입 (기둥-주춧돌 체결용) | Pin 위치, 이동 거리, 삽입력 | 핀 체결 시 |
| IF-06 | Robot ↔ Frame/Panel 스냅핏 구조 | 정렬 후 가압 체결 | 체결 위치, 가압력 | 프레임·패널 체결 시 |
| IF-07 | Robot ↔ Solar Panel | Gripper | Pick 및 설치 동작 | 패널 설치 시 |
| IF-08 | Teach Pendant ↔ HMI | DART/Teach Pendant + 작업 상태, 오류 상태  | Start, Stop, Reset | 사용자 요청 시 |

> **2026-08 설계 변경**: Frame 좌표계 측정(구 IF-06 Robot ↔ Frame Reference, IF-07 Program ↔ Frame Coordinate)은 더 이상 사용하지 않는 기술로 확정되어 제거하고, Frame·Panel 체결에 쓰이는 스냅핏 인터페이스(IF-06)로 대체했다.

소프트웨어 / DB 인터페이스

| IF ID | 연계 대상 | 연계 방식 | 송수신 데이터 | 실행 주기 |
| --- | --- | --- | --- | --- |
| IF-10 | Frontend ↔ Backend | HTTP/REST | Work Order 조회/생성/실행 요청, Execution 상태, Event/Error 조회 | 사용자 요청 시 |
| IF-11 | Backend ↔ Frontend | HTTP/REST | Work Order 상태, 작업 진행 상태, 실행 결과, Event/Error, Dashboard 데이터 | 대시보드 주기 갱신 시 |
| IF-12 | Backend ↔ DB | SQL/ORM | Work Order, Installation Target, Opearation, Component, Execution, Log, Sensor Data | 데이터 조회/저장 시 |
| IF-13 | Backend ↔ ROS Bridge | HTTP/REST | Work Execution ID, Opearation, Parameter | 작업 시작/취소 요청 시 |
| IF-14 | ROS Bridge ↔ 작업 관리 노드 | ROS2 Action | 작업 지시, Operation, Parameter / Feedback, Result | 작업 실행 요청 및 상태 변경 시 |
| IF-15 | 작업 관리 노드 ↔ M0609 | ROS2 | 로봇 제어 명령 / 로봇 상태, 완료, 오류 | 제어 명령 및 상태 변경 시 |
| IF-16 | 작업 관리 노드 ↔ ROS Bridge | ROS2 Action/Topic | 작업 진행 상태, 실행 결과, Event/Error Log | 상태 변경/이벤트 발생 시 |
| IF-17 | ROS Bridge ↔ Backend | HTTP/REST | 실행 상태, 결과, Event/Error Log | 상태 변경/결과, 이벤트 발생 시 |
| IF-18 | Sensor Node ↔ ROS Bridge | ROS2 Topic | Force/Torque Sensor Data | 센서 Sampling 주기 |
| IF-19 | ROS Bridge ↔ Backend | HTTP/REST | Force/Torque Sensor Dat | Batch 단위 전송 |

> **2026-08 구현 현황**: IF-10~14, IF-16, IF-17은 `web_app` ↔ `ros2_bridge` ↔ Controller 구간에 구현·연동이 완료되었다(Work Order 실행 제출 `/jobs`, Feedback/Result 콜백, 강제정지 `/works/<id>/stop`·복구 `/robots/<id>/recover`, `SystemEvent` → `/api/v1/logs` 전달 포함). 강제정지/복구를 수신하는 `StopOperation`/`RecoverRobot` ROS2 Service도 `controller_node.py`에 구현되어 있다(`stop_operation_callback()`, `recover_robot_callback()`). IF-18/19(F/T 센서 → Bridge → Backend 배치 전송)는 아직 구현되지 않았다.

## 4.1 ROS2 인터페이스 구조 상세

| IF ID | 연계 대상 | 방식 | 주요 데이터 | 구현 현황 |
| --- | --- | --- | --- | --- |
| IF-20 | 작업 관리 노드(ROS2 Bridge) ↔ Controller | ROS2 Action (`/execute_operation`) | Work Order ID, Work Execution ID, Operation ID, Operation Code, Parameter, Components | 구현 완료 |
| IF-21 | Controller ↔ 작업 관리 노드(ROS2 Bridge) | ROS2 Action Feedback | operation_execution_id, status, message | 구현 완료 |
| IF-22 | Controller → 작업 관리 노드(ROS2 Bridge) | ROS2 Action Result | 완료/실패, Error Code | 구현 완료 |
| IF-23 | Sensor → 작업 관리 노드 | ROS2 Topic | Force/Torque, Timestamp | ⚠ 미구현 |
| IF-24 | Controller → 작업 관리 노드(ROS2 Bridge) | ROS2 Topic (`/system_event`) | robot_id, severity, code, message, work_execution_id, operation_execution_id 등 | 구현 완료 — Bridge가 구독해 Backend `/api/v1/logs`로 전달 |
| IF-25 | 작업 관리 노드(ROS2 Bridge) ↔ Controller | ROS2 Service (`stop_operation`, `recover_robot`) | work_execution_id / robot_id, operation_execution_id | 구현 완료 — Bridge 호출부 및 Controller 서비스 서버(`controller_node.py`) 양쪽 모두 구현됨 |
