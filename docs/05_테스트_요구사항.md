## 5.1 기능적 테스트 요구사항

| TC ID | 시험 항목 | 시험 방법 | 합격 기준 |
| --- | --- | --- | --- |
| TC-01 | 초기화 | 프로그램 실행 | Tool/TCP/속도/좌표 정상 설정 |
| TC-02 | 기둥 Pick | 공급 위치에서 기둥 Pick | 기둥이 안정적으로 파지됨 |
| TC-03 | 기둥 설치 | 주춧돌에 기둥 삽입 | 기둥이 정상 안착 및 자립 |
| TC-04 | Frame Pick | 공급 위치에서 Frame 이동 | Frame 낙하 없이 이동 |
| TC-05 | Frame 안착 | 기둥 Bracket 위에 Frame 설치 | 잠금 전에도 안정적인 안착 상태 유지 |
| TC-06 | Pin Pick | Pin 공급부에서 파지 | Pin 안정적 파지 |
| TC-07 | Pin 1차 삽입 | 정렬된 체결 구멍에 삽입 | 지정 깊이까지 정상 삽입 |
| TC-08 | Pin 최종 체결 | Pin 재파지/가압 후 완전 삽입 | Pin이 최종 체결 위치에 도달 |
| TC-09 | Frame 기준점 측정 *(⚠ 미구현)* | 설정된 기준점 측정 | 필요한 Point 좌표 획득 |
| TC-10 | Frame 좌표계 생성 *(⚠ 미구현 — `coordinate_manager.py`가 공정 흐름에 미통합)* | 측정 Point 이용 좌표계 생성 | 실제 Frame 경사와 좌표계가 일치 |
| TC-11 | Panel Pick | 공급 위치에서 Panel 파지 | 안정적으로 Panel 이동 |
| TC-12 | Panel 자세 제어 *(⚠ TC-10 선행 필요, 현재 실행 불가)* | Frame 좌표계 기준 자세 변경 | Panel과 Frame 면이 평행 |
| TC-13 | Panel 설치 *(⚠ TC-10 선행 필요, 현재 실행 불가)* | Frame 기준 위치로 이동 및 설치 | 패널이 정상적으로 설치 및 고정 |
| TC-14 | 전체 자동운전 | Start부터 Complete까지 연속 수행 | 중단 없이 전체 공정 완료 |
| TC-15 | 오류 대응 | 삽입 실패 등 오류 발생 | 안전 정지 또는 지정 위치로 후퇴 |

## 5.2 비기능 테스트 요구사항

- 반복 동작 시 부품이 비정상적으로 이탈하지 않아야 한다.
- 프레임 및 패널이 조립 후 안정적인 상태를 유지해야 한다.
- 로봇과 구조물 간 비의도적 충돌이 발생하지 않아야 한다.
- 잠금핀은 반복적인 삽입 및 분리가 가능해야 한다.
- 좌표계 측정 후 패널 설치 위치가 반복적으로 재현되어야 한다.
- 로봇 작업영역 및 Payload 제한을 초과하지 않아야 한다.

정량적인 반복 횟수, 위치 오차, 허용 힘 등의 기준은 실제 시제품 제작 후 확정한다.
