## 5.1 기능적 테스트 요구사항

| TC ID | 시험 항목 | 시험 방법 | 합격 기준 |
| --- | --- | --- | --- |
| TC-01 | 초기화 | 프로그램 실행 | Tool/TCP/속도/좌표 정상 설정 |
| TC-02 | 기둥 Pick | 공급 위치에서 기둥 Pick | 기둥이 안정적으로 파지됨 |
| TC-03 | 기둥 설치 | 주춧돌에 기둥 삽입 | 기둥이 정상 안착 및 자립 |
| TC-04 | Lock Pin Pick (기둥-주춧돌용) | Pin 공급부에서 파지 | Pin 안정적 파지 |
| TC-05 | Lock Pin 1차 삽입 | 기둥-주춧돌 체결 구멍에 삽입 | 지정 깊이까지 정상 삽입 |
| TC-06 | Lock Pin 최종 체결 | Pin 재파지/가압 후 완전 삽입 | Pin이 최종 체결 위치에 도달 |
| TC-07 | Frame Pick | 공급 위치에서 Frame 이동 | Frame 낙하 없이 이동 |
| TC-08 | Frame 안착 | 기둥 Bracket 위에 Frame 설치 | 스냅핏 체결 전에도 안정적인 안착 상태 유지 |
| TC-09 | 스냅핏 체결 (Frame-기둥) | 정렬 후 가압하여 체결 | Frame이 기둥 구조물에서 이탈 불가능한 상태 |
| TC-10 | Panel Pick | 공급 위치에서 Panel 파지 | 안정적으로 Panel 이동 |
| TC-11 | Panel 자세 배치 | Frame 받침대에 걸치도록 이동 | Panel이 Frame 받침대에 안정적으로 걸쳐짐 |
| TC-12 | 스냅핏 체결 (Panel-Frame) | 정렬 후 가압하여 체결 | Panel이 정상적으로 설치 및 고정 |
| TC-13 | 전체 자동운전 | Start부터 Complete까지 연속 수행 | 중단 없이 전체 공정 완료 |
| TC-14 | 오류 대응 | 삽입 실패 등 오류 발생 | 안전 정지 또는 지정 위치로 후퇴 |

> **2026-08 설계 변경**: Frame 좌표계 측정·생성 및 그 기준 Panel 자세 제어 시험(구 TC-09/10/12/13)은 더 이상 사용하지 않는 기술로 확정되어 제거했다. Frame·Panel 체결 시험은 스냅핏 체결 확인으로 대체했다(TC-09, TC-12).

## 5.2 비기능 테스트 요구사항

- 반복 동작 시 부품이 비정상적으로 이탈하지 않아야 한다.
- 프레임 및 패널이 조립 후 안정적인 상태를 유지해야 한다.
- 로봇과 구조물 간 비의도적 충돌이 발생하지 않아야 한다.
- 잠금핀은 반복적인 삽입 및 분리가 가능해야 한다.
- 스냅핏 체결 후 Frame·Panel 설치 위치가 반복적으로 재현되어야 한다.
- 로봇 작업영역 및 Payload 제한을 초과하지 않아야 한다.

정량적인 반복 횟수, 위치 오차, 허용 힘 등의 기준은 실제 시제품 제작 후 확정한다.
