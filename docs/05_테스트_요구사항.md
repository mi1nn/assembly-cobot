| TC-09 | 스냅핏 체결 (Frame-기둥) | 정렬 후 가압하여 체결 | Frame이 기둥 구조물에서 이탈 불가능한 상태 |

| TC-12 | 스냅핏 체결 (Panel-Frame) | 정렬 후 가압하여 체결 | Panel이 정상적으로 설치 및 고정 |

### 5.1.1 작업 관리(Work Order / Recipe) 기능 테스트

조립 공정 시험(TC-01~14)과 번호가 겹치지 않도록 `TC-DB-` 접두사를 사용한다. `docs/03_기능_요구서.md`의 FR-01~11과 1:1 대응한다.

| TC ID | 대응 FR | 시험 항목 | 시험 방법 | 합격 기준 |
| --- | --- | --- | --- | --- |
| TC-DB-01 | FR-01 | Work Order 생성 | 필수 항목을 채워 Work Order 생성 요청 | Work Order가 생성되고, 필수 정보 누락 시 거부됨 |
| TC-DB-02 | FR-02 | Work Order 조회 | ID 및 상태로 조회 | 해당 Work Order 반환, 없는 ID는 오류 응답 |
| TC-DB-03 | FR-03, FR-04 | Installation Target 조회·적용 | Installation Target 조회 후 Work Order에 연결 | 연결된 Installation Target이 Work Order에 반영됨 |
| TC-DB-04 | FR-05 | 작업 단계 조회 | Work Order 실행 시 Operation 목록 조회 | sequence 순서대로 Operation 목록 반환 |
| TC-DB-05 | FR-06 | 작업 Parameter 조회 | Operation의 parameter/components 조회 | 위치·치수·삽입 조건이 누락 없이 반환됨 |
| TC-DB-06 | FR-07 | 작업 상태 갱신 | 실행/완료/실패 이벤트 발생 | 상태가 규정된 전이대로 변경되고 잘못된 전이는 거부 |
| TC-DB-07 | FR-08 | 작업 이벤트 기록 | Operation 시작·완료 이벤트 발생 | `log` 테이블에 이벤트가 timestamp와 함께 기록 |
| TC-DB-08 | FR-09 | 오류 기록 | Operation 실패 유발 | error_code와 발생 위치가 기록됨 |
| TC-DB-09 | FR-10 | 작업 결과 기록 | Operation 실행 완료 | `operation_execution`에 성공/실패 결과 저장 |
| TC-DB-10 | FR-11 | 작업 이력 조회 | Work Order ID로 이력 조회 | 단계별 실행 이력이 시간순으로 반환 |


## 5.2 비기능 테스트 요구사항

- 반복 동작 시 부품이 비정상적으로 이탈하지 않아야 한다.
- 프레임 및 패널이 조립 후 안정적인 상태를 유지해야 한다.
- 로봇과 구조물 간 비의도적 충돌이 발생하지 않아야 한다.
- 잠금핀은 반복적인 삽입 및 분리가 가능해야 한다.
- 스냅핏 체결 후 Frame·Panel 설치 위치가 반복적으로 재현되어야 한다.
- 로봇 작업영역 및 Payload 제한을 초과하지 않아야 한다.

정량적인 반복 횟수, 위치 오차, 허용 힘 등의 기준은 실제 시제품 제작 후 확정한다.
