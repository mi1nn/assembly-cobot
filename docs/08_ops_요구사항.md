# 8. OPS 요구사항

> 상위 문서: 2. 시스템 요구서
> 

| OPS ID | 운영 요구사항 |
| --- | --- |
| OPS-01 | 작업 시작 전에 로봇 주변 장애물을 제거해야 한다. |
| OPS-02 | 주춧돌은 지정된 위치에 사전 설치되어 있어야 한다. |
| OPS-03 | Short Post와 Long Post는 각각 지정된 공급 위치에 배치해야 한다. |
| OPS-04 | Frame은 지정된 공급 위치에 배치해야 한다. |
| OPS-05 | Lock Pin은 로봇이 Pick할 수 있는 별도의 공급 Fixture에 배치해야 한다. |
| OPS-06 | Lock Pin의 1차 삽입과 최종 삽입 모두 로봇이 수행해야 한다. |
| OPS-07 | Frame 체결 완료 후 Frame 좌표계 측정을 수행해야 한다. *(⚠ 미구현 — 현재는 로봇 소프트웨어에 통합되지 않아 수행 불가)* |
| OPS-08 | Panel은 지정된 Pick 위치에 배치해야 한다. |
| OPS-09 | 시스템 실행 전 Tool, TCP, 로봇 기준 좌표계를 확인해야 한다. |
| OPS-10 | 충돌 또는 비정상 체결 발생 시 사용자가 즉시 로봇을 정지시킬 수 있어야 한다. |
| OPS-11 | 시연 종료 후 구조물을 분해하여 초기 상태로 복원할 수 있어야 한다. |
