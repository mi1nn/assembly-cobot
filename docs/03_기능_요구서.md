## 3.1 Traceability Matrix

우선순위는 다음과 같이 정의한다.

- **H** : 필수
- **M** : 중요
- **L** : 선택

상위 요구는 **상위 BR(비즈니스 요구)**과 **상위 SYS-FR(시스템 요구)**을 분리하여 표시한다. 하나의 FR이 여러 SYS-FR을 함께 만족시키는 경우도 있어 SYS-FR은 콤마로 병기한다.

## 3.2 잠금핀 체결 기능 상세

잠금핀 조립은 다음과 같은 **2단계 삽입 공정**으로 수행한다.

### 1단계: 프레임 안착

로봇이 프레임을 기둥 상부 브라켓 위에 내려놓는다. 이때 프레임은 브라켓의 안착면에 의해 자체적으로 지지되어야 한다.

### 2단계: 잠금핀 Pick

로봇은 프레임에서 그리퍼를 해제한 후 잠금핀 공급 위치로 이동한다. 잠금핀을 그리퍼로 파지한다.

### 3단계: 잠금핀 1차 삽입

로봇은 프레임과 Bracket의 정렬된 체결 구멍으로 Pin을 이동시킨다. Pin을 완전히 삽입하지 않고 **설정된 깊이까지만 우선 삽입**한다.

### 4단계: 잠금핀 재파지 및 최종 삽입

로봇은 필요에 따라 그리퍼의 파지 위치를 변경하여 Pin Head 또는 노출된 부분을 안정적으로 파지한다. 이후 Pin 축 방향으로 힘을 가해 최종 위치까지 삽입한다.

### 5단계: 체결 완료

Pin이 완전히 삽입되면 프레임이 기둥 상부 브라켓에서 이탈할 수 없는 상태가 된다.

## 3.3 전체 기능 흐름

```
시스템 초기화
   ↓
Short / Long Post Pick
   ↓
주춧돌에 기둥 설치
   ↓
Frame Pick
   ↓
기둥 상부 Bracket에 Frame 안착
   ↓
Lock Pin 공급 위치 이동
   ↓
Lock Pin Pick
   ↓
Frame-Bracket 체결 구멍에 Pin 1차 삽입
   ↓
Pin 재파지 또는 Push 자세 변경
   ↓
Lock Pin 완전 삽입
   ↓
Frame 기계적 체결 완료
   ↓
Frame 기준점 측정          ⚠ 미구현
   ↓
Frame Coordinate 생성      ⚠ 미구현 (coordinate_manager.py 단독 구현, 공정 흐름 미통합)
   ↓
Panel Pick
   ↓
Frame Coordinate 기준 Panel 자세 변경   ⚠ 선행 단계 미구현으로 현재 실행 불가
   ↓
Frame 좌표계 기준 설치 위치 접근       ⚠ 선행 단계 미구현으로 현재 실행 불가
   ↓
Panel 기계식 설치
   ↓
작업 완료
```
