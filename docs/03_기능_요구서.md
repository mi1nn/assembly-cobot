## 3.1 Traceability Matrix

우선순위는 다음과 같이 정의한다.

- **H** : 필수
- **M** : 중요
- **L** : 선택

상위 요구는 **상위 BR(비즈니스 요구)**과 **상위 SYS-FR(시스템 요구)**을 분리하여 표시한다. 하나의 FR이 여러 SYS-FR을 함께 만족시키는 경우도 있어 SYS-FR은 콤마로 병기한다.

## 3.2 잠금핀 체결 기능 상세

기둥-주춧돌 체결은 다음과 같은 **2단계 삽입 공정**으로 수행한다 (FR-13~15).

### 1단계: 기둥 설치

로봇이 기둥을 지정된 주춧돌에 삽입한다. 잠금핀 삽입 전에도 기둥이 주춧돌 삽입 구조만으로 자립해야 한다.

### 2단계: 잠금핀 Pick

로봇은 잠금핀 공급 위치로 이동해 잠금핀을 그리퍼로 파지한다.

### 3단계: 잠금핀 1차 삽입

로봇은 기둥과 주춧돌의 정렬된 체결 구멍으로 Pin을 이동시킨다. Pin을 완전히 삽입하지 않고 **설정된 깊이까지만 우선 삽입**한다.

### 4단계: 잠금핀 재파지 및 최종 삽입

로봇은 필요에 따라 그리퍼의 파지 위치를 변경하여 Pin Head 또는 노출된 부분을 안정적으로 파지한다. 이후 Pin 축 방향으로 힘을 가해 최종 위치까지 삽입한다.

### 5단계: 체결 완료

Pin이 완전히 삽입되면 기둥이 주춧돌에서 이탈할 수 없는 상태가 된다.

## 3.3 스냅핏 체결 기능 상세

Frame-기둥 체결(FR-18)과 Panel-Frame 체결(FR-21)은 Lock Pin의 2단계 삽입 없이, 정렬 후 가압하는 **단일 동작의 스냅핏 체결**로 수행한다. Frame의 하중은 스냅핏이 아닌 기둥 상부 Bracket 안착면이 지지하며, 스냅핏은 이탈 방지와 최종 고정 역할만 담당한다.

## 3.4 전체 기능 흐름

```
시스템 초기화
   ↓
Short / Long Post Pick
   ↓
주춧돌에 기둥 설치
   ↓
Lock Pin 공급 위치 이동 → Lock Pin Pick
   ↓
기둥-주춧돌 체결 구멍에 Pin 1차 삽입
   ↓
Pin 재파지 또는 Push 자세 변경
   ↓
Lock Pin 완전 삽입 (기둥-주춧돌 체결 완료)
   ↓
Frame Pick
   ↓
기둥 상부 Bracket에 Frame 안착
   ↓
스냅핏 체결 (Frame-기둥 고정)
   ↓
Panel Pick
   ↓
Panel을 Frame 받침대에 걸치도록 배치
   ↓
스냅핏 체결 (Panel-Frame 설치)
   ↓
작업 완료
```
