# 10. 최종 시스템 시나리오

> 상위 문서: 3. 기능 요구서
> 

본 프로젝트의 전체 시나리오는 다음과 같다.

1. 바닥 및 주춧돌은 사전에 설치한다.
2. 로봇이 Short Post와 Long Post를 공급 위치에서 Pick한다.
3. 각각의 기둥을 지정된 주춧돌에 설치한다.
4. 기둥을 설치하면 잠금핀을 체결해 기둥과 주춧돌을 고정한다.
5. 로봇이 Frame을 Pick한다.
6. Frame을 기둥 상부에 안착시킨다.
7. 로봇이 Frame에서 그리퍼를 해제한다.
8. 스냅핏 체결을 통해 Frame을 기둥 구조물에 고정한다.
9. 로봇이 태양광 Panel을 Pick한다.
10. Panel의 자세를 Frame의 받침대에 걸치도록 놓는다.
11. Panel을 스냅핏 체결 구조를 이용하여 Frame에 설치한다.
12. 로봇이 안전 위치로 복귀한다.
13. 전체 공정을 완료한다.

> **참고**: 본 시나리오는 Frame 좌표계 측정 단계를 포함하지 않는다. 해당 기술은 2026-08 설계 변경으로 **폐기 확정**되었으므로 향후에도 추가하지 않는다(§02·§03·§06 참조).

> **2026-08 구현 현황**: 2·3·5~13번은 Controller의 DB Operation(`post1`~`post6`, `frameA`, `solarpanelA`)으로 구현·연결되어 있다. **4번(잠금핀 체결)은 미연결 상태**다. `solar_motion.py`에 `pick_pin()`/`place_pin()`이 구현되어 있으나 어떤 DB Operation 흐름에서도 호출되지 않으며(수동 테스트 코드 `POST_PIN_PICK`/`POST_PIN_PLACE`로만 실행 가능), DB에도 대응 Operation이 없다.
