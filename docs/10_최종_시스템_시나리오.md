# 10. 최종 시스템 시나리오

> 상위 문서: 3. 기능 요구서
> 

본 프로젝트의 전체 시나리오는 다음과 같다.

1. 바닥 및 주춧돌은 사전에 설치한다.
2. 로봇이 Short Post와 Long Post를 공급 위치에서 Pick한다.
3. 각각의 기둥을 지정된 주춧돌에 설치한다.
4. 기둥을 설치하면 잠금핀을 체결해 기둥과 주춧돌을 고정한다. 
5. 로봇이 Frame을 Pick한다.
7. Frame을 기둥 상부에 안착시킨다.
8. 로봇이 Frame에서 그리퍼를 해제한다.
9. Snap Pin 체결을 통해 Frame을 기둥 구조물에 고정한다.
10. 로봇이 태양광 Panel을 Pick한다.
11. Panel의 자세를 Frame의 받침대에 걸치도록 놓는다.
12. Panel을 Snap Pin 체결 구조를 이용하여 Frame에 설치한다.
13. 로봇이 안전 위치로 복귀한다.
14. 전체 공정을 완료한다.

> **참고**: 본 시나리오는 Frame 좌표계 측정(FR-18/19) 단계를 포함하지 않는다. 이는 현재 로봇 소프트웨어에 해당 기능이 아직 통합되지 않은 상태(§03 기능 요구서 참조)와 일치한다. 통합 완료 시 13번과 14번 사이에 "Frame 기준점 측정 → Frame 좌표계 생성" 단계를 추가해야 한다.
