## 1.1 프로젝트 배경 및 목적

기존의 산업용·협동로봇 실습은 미리 지정된 위치를 이용하여 물체를 이동시키는 단순 Pick & Place 공정에 집중되는 경우가 많다.

하지만 실제 구조물 설치 환경에서는 여러 부품을 순차적으로 조립해야 하며, 앞 단계에서 조립된 구조물의 실제 자세를 기준으로 다음 작업을 수행해야 하는 경우가 존재한다.

본 프로젝트에서는 지상형 태양광 패널 설치 공정을 대상으로 하여, 로봇이 기둥을 주춧돌에 잠금핀으로 기계적으로 체결하고, 이어서 프레임과 패널을 순차적으로 Pick하여 스냅핏 구조로 기계적으로 체결하도록 한다.

이를 통해 단순 Pick & Place가 아닌 다음 기술을 구현하는 것을 통해 반복 작업의 자동화, 현장 사고율 감소 효과를 볼 수 있다. 뿐만 아니라 작업 결과의 후속 데이터를 통해 재고 관리를 통해 장기적으로 비용 절감을 목적으로 한다. 

- 다단계 구조물 자동 조립
- 높이가 다른 기둥을 이용한 경사 구조 형성
- 로봇을 이용한 잠금핀 Pick 및 F/T 센서 기반 단계적 삽입 (기둥-주춧돌 체결)
- 스냅핏 구조를 통한 프레임·패널 기계적 체결
- 태양광 패널 자동 설치

추가적으로 프로젝트를 수행하는 데에 현장 작업자의 역할과 시스템을 구분해 보았다. 

- Human User - 현장 관리자 : 작업 지시, 작업 상태 모니터링, 예외 상황 대응, 작업 결과 확인
- System Actor - 협동로봇 작업 관리 노드 : Work Order 조회, Recipe 기반 작업 실행
- System - DB : 작업 지시, Recipe, 작업 이력, 센서 및 측정 데이터 관리, 작업 상태 및 결과 기록
- System - 협동로봇 제어 시스템 : 작업 관리 노드의 지시에 따라 실제 로봇 작업 수행

## 1.2 비즈니스 목표

| ID | 비즈니스 목표 | 성공 기준 |
| --- | --- | --- |
| BR-01 | 실제 산업 설치 공정을 모사한 로봇 자동화 시스템 구축 | 조립 → 체결 → 후속 조립의 전체 공정 수행 |
| BR-02 | 작업 지시와 공정 데이터를 기반으로 한 작업 관리 체계 구현 | Work Order, Recipe, 작업 상태 및 결과 관리 |
| BR-03 | 작업 결과를 후속 공정에 활용하는 데이터 기반 자동화 구현 | 각 체결 단계(Lock Pin, 스냅핏)의 성공 여부·센서 값을 기록하고 다음 단계 진행 판단에 활용 |
| BR-04 | 패널은 자석이 아닌 기계식 구조로 프레임에 고정 | 패널이 프레임에 고정되어 흔들림이 없어야 함 |
| BR-05 | 반복 가능한 자동화 공정 구축 | 초기 상태 복원 후 동일 공정 반복 수행 |
| BR-06 | 로봇 자동화 교육 및 실무 프로젝트 활용성 확보 | 산업 현장의 작업 관리 및 자동화 흐름을 모사 |

> **2026-08 구현 현황**: BR-02(작업 지시/공정 데이터 관리)는 `web_app`(Flask + PostgreSQL) 프론트엔드·백엔드·DB로 구현이 완료되었다.
>
> **2026-08 설계 변경**: Frame 좌표계 측정 및 그 기준 Panel 설치 활용은 더 이상 사용하지 않는 기술로 확정되었다. BR-03은 체결 결과(Lock Pin/스냅핏 성공 여부, 센서 값) 활용으로 범위를 조정했다. 상세는 CLAUDE.md·`docs/10_최종_시스템_시나리오.md` 참조.

## 1.3 프로젝트 범위

### 포함 범위

| 항목 | 내용 |
| --- | --- |
| 바닥 | 사전 제작 및 고정 |
| 주춧돌 | 사전 제작 및 지정 위치에 고정 |
| 기둥 | 로봇을 이용한 Pick 및 설치 |
| 기둥 종류 | 높이가 다른 Long Post와 Short Post 사용 |
| 프레임 | 로봇을 이용한 Pick 및 기둥 상부 설치 |
| 잠금핀 (기둥-주춧돌 체결용) | 로봇이 공급 위치에서 직접 Pick |
| 잠금핀 1차 삽입 | 로봇이 체결 구멍에 핀을 일정 깊이까지 삽입 |
| 잠금핀 최종 체결 | 로봇이 핀을 다시 파지 또는 가압하여 끝까지 삽입 |
| Frame-기둥 체결 | 스냅핏 구조로 정렬 후 가압하여 기계적으로 고정 |
| 패널 | 로봇으로 Pick하여 경사진 프레임에 설치 |
| 패널 체결 | 자석이 아닌 스냅핏(기계적) 방식 사용 |
| 로봇 프로그램 | 전체 자동 조립 Sequence 구현 |

### 제외 범위

- 부품 형상 자동 인식
- 카메라를 이용한 부품 종류 판별ㅈ
- 무작위 위치에 놓인 부품 자동 탐색
- 주춧돌 위치 자동 탐색
- 태양 위치 자동 추적
- 실제 발전량 제어
- 자석을 이용한 구조물 체결
- 산업용 볼트·너트 자동 체결 (해당 여부 추후 결정)
- 실제 야외 태양광 발전설비 규모의 시공

## 1.4 상세 요구사항

시스템의 기본 구조는 다음과 같다.

> **주춧돌 → 기둥 → 경사 프레임 → 태양광 패널**
> 

패널 경사는 높이가 다른 기둥을 이용하여 형성한다.

기본 설계안은 다음과 같다.

| 구성품 | 기본안 |
| --- | --- |
| 주춧돌 | 사전 고정 |
| Short Post | 낮은 측 기둥 |
| Long Post | 높은 측 기둥 |
| Frame | 경사진 패널 지지 구조 |
| Lock Pin | 기둥과 주춧돌을 기계적으로 고정 |
| Solar Panel Mock-up | 최종 설치 대상 |
| Panel Fixture | 스냅핏 기계식 고정 구조, 상세 방식 추후 확정 |

기본 구조는 **Long Post 3개 + Short Post 3개의 6기둥 방식**을 우선안으로 한다.

기둥 높이 차이를 이용해 프레임의 경사를 생성하며, 정확한 기둥 높이와 프레임 경사각은 상세 CAD 설계 과정에서 결정한다.
